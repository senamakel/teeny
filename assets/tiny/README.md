# Tiny, as published

The account's own artwork, copied from the marquee on
[tinyhumansworld.com](https://tinyhumansworld.com/) on 2026-09-14. These are
what Tiny looks like. The vision ladder studies them once at startup, a text
step distils the descriptions into one character sheet, and the sheet is
prepended to every image or video prompt that features Tiny, so a generated
picture is a picture of *this* robot rather than some other one.

Vendored rather than fetched so the sheet can be built with the site down, and
so a redesign of the site does not silently change what the account draws.
`TINY_REFERENCE_IMAGES` overrides the list (paths or URLs, comma separated;
`none` disables the sheet). The built sheet is cached at
`REFERENCE_SHEET_PATH` and rebuilt when this list changes.
